Discord Unblocked

A browser proxy running on a Cloudflare Worker. Type a link and the page loads through the Worker, including WebSockets.

Keep this tab open while you browse — the tunnel runs here. Discord's app files (discord.com/assets) are refused to Cloudflare Worker traffic by Discord itself, so discord.com/app loads blank through this proxy. Discord's REST API and gateway do respond. Everything else proxies normally.
